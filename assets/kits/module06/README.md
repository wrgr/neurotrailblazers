# Module 06 kit: flagged candidates for correction triage

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

This kit is the flag list for the Module 06 correction triage simulation: 25 candidates flagged by automated detection in a 50 x 50 x 50 µm subvolume of about 200 fragments, ahead of a connectivity analysis of 40 L2/3 pyramidal cells. You have time to fix 10. The flag reason is what the detector saw; the error type (merge, split, boundary or uncertain) is yours to assign.

| File | Who opens it | What it is |
|---|---|---|
| `flagged_candidates.csv` | Learners | The flag list you triage. It shows only what a proofreader sees before editing. |
| `ground_truth.csv` | Instructor | What each fix would actually change. Hold it back until rankings are committed. |
| `kit.json` | Script | Totals for the analysis set, the fix budget, and file names. |
| `qc_metrics.py` | Everyone | Computes before/after quality indicators for a list of fixed IDs. Python 3, no packages. |

**Fixing on paper.** No public volume lets a class edit a segmentation, so a "fix"
here means: you commit to correcting a flagged item, write its log line, and then
let the script apply what that correction would have changed. The script stands
in for re-measuring against a proofread reference region. It knows the answer;
you do not, which is the situation a real triage is in.

```bash
python3 qc_metrics.py                      # baseline, nothing fixed
python3 qc_metrics.py --fixed C02,C09,C14     # after your fixes (IDs comma-separated)
```

**Run-of-show guided round.** The 22:00-36:00 pairs exercise uses three candidates chosen by the instructor from this file: one the class will agree is a merge, one a split, and one of the `implausible morphology` rows whose note says the membrane looks continuous (the ambiguous case).

**What the script reports.** Edge precision and recall for the analysis set, the
number of analysis objects still outside the plausible size range for their type,
synapses still attributed to the wrong neuron, and how many of your fixes were
spent on items that were not errors. Those are the before/after indicators the
rubric asks you to attach to each correction.

**What this kit cannot teach.** Reading the evidence in the image. Every flag here
arrives with a written note; in a real volume the note is what you have to produce.
Practice that part on a public volume (the [proofreading side quest](/side-quests/proofreading/)
uses real data), and use this kit for the part that is about allocation.
