# Module 09 kit: ten skeletons and a synapse-based classification

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

The Module 09 comparative morphometry activity: ten dendritic skeletons in a
300 x 300 x 220 µm volume, a table of spine positions, and a synapse-based
excitatory/inhibitory call for each cell to compare your morphological call
against (studio step 4).

| File | What it is |
|---|---|
| `skeletons/cell01.swc` ... `cell10.swc` | Dendrites in SWC (id, type, x, y, z, radius, parent). Axons are not included. |
| `spines.csv` | One row per spine: the cell and the skeleton node it sits on |
| `synapse_labels.csv` | The synapse-based call, from each cell's output synapses (not included as geometry) |
| `volume.json` | Volume bounds, so you can tell a real tip from a cut at the face |
| `morphometry.py` | Computes the five studio descriptors, per-dendrite detail and Sholl counts. Python 3, no packages. |

```bash
python3 morphometry.py                       # descriptor table for all ten cells
python3 morphometry.py --cell cell07 --detail  # per-dendrite cable, spines, face contact
python3 morphometry.py --cell cell02 --sholl 10  # Sholl intersections every 10 µm
```

If you have NeuroM installed you can load the SWC files with it instead; the
script exists so that nobody is blocked by an install.

**What is planted.** At least two cells will not classify cleanly from whole-cell
descriptors, for two different reconstruction reasons. The studio asks you to find
the reason, not just the mismatch. The instructor key is in the Module 09 row of
`docs/reviews/2026-09-kit-materials-audit.md` in the repository, not on the site.

**"Arbor volume."** The script reports the axis-aligned bounding box of the
dendrites. That is a crude stand-in for a convex hull and overstates the volume of
oblique arbors; say so if you use it.
