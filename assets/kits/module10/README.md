# Module 10 kit: a 500-neuron column graph

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

The graph for the Module 10 graph analysis report: 500 neurons in a
400 x 400 x 950 µm synthetic cortical column, 11,388 directed edges at a
threshold of one synapse (55% of them carry exactly
one synapse). It stands in for a MICrONS column;
the [Dataset Access](/datasets/access/) page lists how to pull a real one.

| File | What it is |
|---|---|
| `nodes.csv` | One row per neuron: cell type, layer, soma position (y is depth from the pia) and the number of somata in the object |
| `edges.csv` | One row per directed connection with its synapse count; filter `synapses >= 3` for the second threshold |

```python
import pandas as pd
nodes = pd.read_csv("nodes.csv")
edges = pd.read_csv("edges.csv")
print(len(nodes), len(edges), len(edges) / (len(nodes) * (len(nodes) - 1)))
# networkx: nx.from_pandas_edgelist(edges, "pre_id", "post_id", "synapses", create_using=nx.DiGraph)
```

**How it was built, which you need for the null-model discussion.** Connection
probability depends on the two cell types and falls off with soma distance
(length constant 150 µm). A degree-preserving null therefore does not remove the
spatial structure; a spatial null would. One object in `nodes.csv` has
`soma_count` 2. Treat what you find there the way the module's worked example does.
