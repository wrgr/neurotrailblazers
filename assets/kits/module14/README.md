# Module 14 kit: model comparison by region and a failure-case log

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

The Module 14 studio compares two segmentation models on a clean ground-truth
region and a smaller artifact-heavy one. No public release ships two competing
models with matched ground truth, so this kit supplies the evaluation outputs
instead of the volumes.

| File | Who opens it | What it is |
|---|---|---|
| `model_comparison.csv` | Learners | VI (total, split, merge), ERL, boundary F1, split and merge counts, per model and region. The clean rows are the worked example's numbers. |
| `failure_cases.csv` | Learners | 30 failure cases, each with the viewer observation a reviewer wrote down. Classify the cause of at least 15. |
| `failure_cases_key.csv` | Instructor | The cause each observation was written to illustrate. |

Causes to choose from: weak stain, section loss, fold, thin neurite, genuine
ambiguity. Some observations are written so that two causes are defensible; the
key records one, and a well-argued alternative should get credit.

**What this kit cannot teach.** Looking at the failures yourself. Do that on the
subvolume you brought to class (pre-class preparation), and use this kit for the
arithmetic and the model card.
