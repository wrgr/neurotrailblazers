# Module 16 kit: data for the figure package

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

Data for the Module 16 figure build (20:00-35:00) and the three-figure studio
package. Load it into whichever plotting tool you use; the activity is the figure,
not the loading.

| File | Figure | What it is |
|---|---|---|
| `celltype_synapses.csv` | 1 | 50 x 50 synapse counts, rows presynaptic type, columns postsynaptic type |
| `celltype_connections.csv` | 1 | Number of connected neuron pairs behind each cell; hatch cells under 10 (studio) or 5 (warm-up) |
| `neurons/excitatory.swc`, `basket.swc`, `chandelier.swc` | 2 | Three example dendritic arbors, soma at the origin |
| `neurons.csv` | 2 | Estimated fraction of cable missing from each reconstruction, for the uncertainty band |
| `input_synapses_by_layer.csv` | 3 | Input synapse counts for 160 excitatory neurons across four layers |
| `morphometry.py` | 2 | `python3 morphometry.py --swc neurons/basket.swc --sholl 10` prints Sholl counts |

For the warm-up the run-of-show describes a 20 x 30 matrix: take any 20 rows and
30 columns of `celltype_synapses.csv`. For the "reconstructed neuron" in the
warm-up, use `neurons/excitatory.swc`; a Sholl plot needs a skeleton, not a mesh.

```python
import pandas as pd
syn = pd.read_csv("celltype_synapses.csv", index_col="pre_type")
conn = pd.read_csv("celltype_connections.csv", index_col="pre_type")
sparse = conn < 10          # cells to hatch in Figure 1
print(syn.shape, int(sparse.values.sum()), "sparse cells")
```

**Units and honesty.** Counts are synapses; the uncertainty band in Figure 2 is
your choice of method, and the caption must say what it is. A band built from
`est_missing_cable_fraction` shows reconstruction incompleteness, not biological
variability.
