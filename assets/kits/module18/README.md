# Module 18 kit: a noisy export to clean

> **Synthetic teaching data.** Every number in this kit was generated by
> `scripts/generate_kit_materials.rb` from a fixed random seed. None of it is sampled from MICrONS, H01,
> FlyWire or any other real dataset, and no result computed from it is a finding
> about a brain. The distributions were chosen by hand so that one teaching point
> is visible; real data are messier in ways this kit does not model.

A small stand-in for the export in the Module 18 scenario. The scenario's tables
are millions of rows; these are 30,450 synapses, 2,000 segments and
407 cell-type annotations, which is enough to see every defect and small
enough to open on a laptop. Report counts as fractions so they transfer.

| File | What it is |
|---|---|
| `noisy_synapses.csv` | Synapses with a cleft score (0-255). The score distribution is bimodal. |
| `segments.csv` | Segment volumes spanning about five orders of magnitude, with soma and boundary flags |
| `cell_types.csv` | Cell-type labels for segments with a soma; some are blank |

Defects to find, each planted on purpose: duplicated synapse rows, autapses
(pre equals post), synapse endpoints that are not in the segment table, a debris
tail of tiny segments, boundary-touching neurons, and missing cell-type labels.
