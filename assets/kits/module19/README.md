# Module 19 kit: mock preprint and review form

> **Fictional teaching material.** The preprint in this kit does not exist and
> reports no real analysis. It was written so that four problems are findable.

| File | What it is |
|---|---|
| [`mock-preprint.md`](mock-preprint.md) | Abstract, methods, results with two figure legends, discussion and contributions, with four seeded issues |
| [`review-form.md`](review-form.md) | Structured review form, ethics-risk checklist, and two example reviewer comments written for the session |

**Instructor key (do not hand out).** The four seeded issues are: a methods gap
([M1] gives no synapse confidence threshold and no boundary handling); an
overclaim ([D1] and [D2], "establish", "dominant organizing principle", "causal
role"); an attribution problem (a consortium listed without individual
contributions); and selective reporting ([M3] tests three motifs, the results
discuss one). A strong review also notices that Figure 2 has no uncertainty and
that twelve interneurons carrying half of all loops is a merge-error check the
authors did not report.
