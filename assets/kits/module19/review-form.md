# Module 19 review form and ethics-risk checklist

Use with the [mock preprint](mock-preprint.md). Cite paragraph labels
([M1], [R2], [D1]) and figure numbers in every comment.

## Structured review form

| Section | Your entry |
|---|---|
| Claims the paper makes (list each, with its paragraph label) | |
| Methods audit: what is missing, why it matters, what to add | |
| Evidence gaps: which figure or number does not support which claim | |
| Uncertainty: which figure panel hides it | |
| Interpretation audit: the sentence that overclaims, and its bounded version | |
| Recommendation (accept with revisions, major revisions, reject) and the concerns it rests on | |

## Ethics-risk checklist

- [ ] **Human tissue.** Does the paper use human-derived data? If so, is consent and de-identification described?
- [ ] **Attribution.** Can a reader tell who did what? Is a group listed without individual contributions?
- [ ] **Data sharing.** Are the exact data version, code and derived tables available?
- [ ] **Selective reporting.** Are all tested hypotheses reported, including the null results?

## Two example reviewer comments

These were written for this session. They are not taken from a real review.

**Comment 1.** "The methods do not state the synapse confidence threshold or how
neurons touching the volume boundary were handled ([M1]). Both change the edge
count, and truncated neurons lose partners non-uniformly. Please report the
threshold, re-run the motif count at a second threshold, and state how many
neurons were excluded or retained at the boundary."

**Comment 2.** "The analysis is not convincing and the conclusions are overstated.
The authors should do more work before this is publishable."

Which comment could the authors act on tomorrow, and what is missing from the
other?
