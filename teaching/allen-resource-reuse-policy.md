# Allen Institute / AIBS Resource Reuse Policy for NeuroTrailblazers

## Principle

**Link and scaffold; do not duplicate mature scientific-resource training.**

Allen Institute already maintains authoritative scientific browsers, database guides, and educator-facing material. NeuroTrailblazers should add pedagogical value around those resources rather than create parallel manuals that will drift out of date.

## USE / ADAPT / LINK rules

### LINK
Use a direct link when Allen already provides:
- interface instructions;
- user manuals;
- database navigation;
- official dataset documentation;
- maintained notebooks.

### ADAPT
Create a NeuroTrailblazers wrapper when learners need:
- a scientific question;
- prerequisites;
- a short glossary;
- an interpretation task;
- a comparison to another map type;
- an assessment;
- a connection to CONNECTS.

### BUILD
Build original material only when the learning objective is not already served by Allen's resource.

Examples:
- Atlas vs. Connectome conceptual activity;
- projectome vs synaptic-connectome comparison;
- public investment / Grant Detective;
- evidence/impact literacy;
- hidden curriculum;
- career and contribution pathways.

## ABC Atlas example

**Do not build:** another button-by-button ABC Atlas manual.

**Do build:**
> Use the Allen ABC Atlas to find two cell populations. What evidence defines them? What does the atlas tell you that a connectome would not? What would you need next to ask who they connect to?

## MICrONS example

**Do not build:** a competing MICrONS viewer tutorial when official teaching material exists.

**Do build:**
> Use the authentic resource to compare structure and activity. Which claims rely on anatomy? Which rely on activity? Which require both?
