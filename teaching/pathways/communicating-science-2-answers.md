These responses use the worksheet's **invented** case. They are examples, not the only
acceptable wording. This page is public and suitable for formative feedback.

## 1. The Q&A, typed and repaired

| # | Type | What went wrong | Better |
|---|---|---|---|
| 1 | Clarification | Two minutes for a one-sentence question | "A frozen snapshot of the reconstruction, so the numbers don't shift while edits continue. Mine is release T12." |
| 2 | Methods challenge | Defensive: asserts quality, names no evidence | See below |
| 3 | Scope | Optimistic extrapolation | "No. This is anatomy in one mouse cortex volume. It says where synapses are, not what they do in any disease." |
| 4 | Positioning, as a comment | Argued instead of thanking | "Thank you. Could you send me the reference? I'd like to compare the null models." |
| 5 | "So what" | Over-conceded, then stopped with nothing | "Yes, the pattern is long described. What's new is a count against a stated null across every fully proofread axon, so the size of the effect is now a number people can test." |

**The repaired methods answer:** "That's a real mechanism. If proofreaders finish the
axon near the cell body first, the fully proofread set would be biased toward it. The
partly proofread neurons still show the effect, at 2.1×, so I don't think it is all
proofreading order. But the drop from 2.7 is in the direction your worry predicts, so
some of it may be. What I haven't done is compare targeting on axon stretches proofread
early versus late. That's the test."

**The costliest answer** is number 2. It was the one real challenge, and "very thorough"
tells the room Rosa has not thought about her failure mode. Accept number 5 if the learner
argues that "I guess, yes" invites the room to discount the whole talk; Module 22 treats
over-conceding as the same calibration failure as over-claiming. Note that number 1, the
easiest question, got the longest answer. That pattern is common and worth naming aloud.

## 2. Model five-minute outline (Rosa's result)

| Time | Slot | Notes |
|---|---|---|
| 0:00–0:45 | Question and stake | Where do inhibitory synapses land on excitatory cells? Circuit models assume an answer; this counts it in one volume. |
| 0:45–1:45 | Data and method | One fictional mouse cortex volume, layer 2/3, release T12; 58 fully proofread axons; null keeps synapse counts, shuffles position. "Inhibitory" from synapse shape. |
| 1:45–3:45 | Result | 2.7× near the cell body, "consistent with" targeting. 2.1× on partly proofread axons, wider interval. |
| 3:45–4:30 | Limitation and non-claim | Proofreading order could bias it. This does not show these synapses change firing. |
| 4:30–5:00 | Next step | Compare early- and late-proofread stretches; ask a physiologist what would test function. |

**Opener, about 40 seconds:** "Where do inhibitory synapses land on the cells they
contact? Circuit models assume an answer. I counted them, synapse by synapse, in one
volume, and they land near the cell body almost three times more often than chance.
The obvious worry is that proofreaders fix those stretches first, so I'll show
you the partly proofread neurons too."

## 3. Sample question bank

1. Methods: how was "cell body or first 20 µm" chosen, and does the result move if it is 10?
2. Alternative: could the null be wrong, because cell bodies have more membrane nearby?
3. Scope: would this hold in layer 5?
4. Positioning: how does this compare with physiology papers on the same cells?
5. "So what": what would change in a model if the number were 1.5 instead?
6. Clarification: how many animals?
7. Methods: how many neurons are called inhibitory wrongly by shape?
8. Cannot yet answer: does the ratio differ between inhibitory subtypes?

A strong answer to 8: "I don't know. I haven't split by subtype because shape alone
doesn't separate them. That needs a marker, and it's the next dataset I'd look for." Then
stop.

## 4. Live round: what the timekeeper should see

A good round sounds like this. The speaker says "that's a scope question," answers in
two sentences, and stops. The next answer is longer because it is a methods challenge,
and it ends on a test. Feedback names one answer and one reason ("the second one, because
you said what you hadn't done"). Weak rounds show the same length for every question,
or an answer that stops only when the timekeeper speaks.

## 5. Personal pattern: what good looks like

The private section is not collected. Learners who share it tend to show two patterns.

**Strong:** names one default ("I keep talking until someone nods") with a specific
example, and turns the feared question into a task ("I need to know the misclassification
rate for shape-based typing; I'll ask the lab manager").

**Weak:** "I get nervous" with no pattern, or a feared question that is really about the
learner ("they'll see I'm not smart enough"). Name that gently: it is a belonging question,
covered in [STEM Identity and
Purpose]({{ '/teaching/pathways/identity-and-purpose/' | relative_url }}), not a gap in the
bank.

## Feedback rubric

Score four dimensions **0–2 each**:

1. **Questions typed.** 2 = all five transcript questions typed plausibly and each repair
   fits the type; 1 = three or four; 0 = judged on content only.
2. **Outline budgeted.** 2 = every slot filled and the limitation slot holds a non-claim;
   1 = limitation present but vague; 0 = no limitation time.
3. **Bank covers the ground.** 2 = eight questions, all required types, one unanswerable,
   three answers of 40 seconds or less ending in a test or boundary; 1 = gaps in one of
   those; 0 = fewer than five questions or only friendly ones.
4. **Live answers stop.** 2 = type named aloud and both answers stopped when done, per the
   timekeeper; 1 = one of the two; 0 = neither.

A proficient response scores at least 6/8 with no zero on dimension 4. This is a local
teaching rubric, not a validated assessment instrument.

Do not grade accent, fluency, speed or visible nerves. A slow answer that names the type,
concedes the valid part and stops is the target.
