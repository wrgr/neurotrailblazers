**Time:** 38 minutes in pairs, then 12 minutes alone. The case below is **invented**.
Tomás, Dr. Brennan, Dr. Idris and Dr. Lindqvist are not real people.

## The case

Tomás is a second-year PhD student in Dr. Brennan's connectomics lab. His offer letter
said "funded for five years". In one week, five things happen.

1. **Monday.** A labmate mentions that the lab's main award ends next summer and "the
   renewal is in". Tomás did not know his stipend was tied to any award.
2. **Tuesday.** Dr. Idris, a postdoc, circulates a paper draft. It uses 900 segments
   Tomás proofread and the synapse QC script he wrote, which the whole lab now runs. Tomás
   is in the acknowledgments. Nobody discussed authorship.
3. **Wednesday.** Dr. Lindqvist, at another university, emails Dr. Brennan: "Could Tomás
   run his QC script on our volume? Should be quick." Dr. Brennan replies, copying Tomás:
   "Sure, Tomás can help."
4. **Thursday.** Another lab paper comes back with major revisions. Reviewer 2 demands
   three new analyses. The editor's letter says: "Please address the concerns about
   synapse detection accuracy." Dr. Brennan asks Tomás to "handle the synapse part of the
   response".
5. **Friday.** Dr. Brennan forwards a manuscript she has agreed to review: "Could you
   draft comments on the methods by Tuesday? I'll send it in."

## 1. Map the machine (20 minutes, pairs)

For each of the five threads, fill in one row.

| Thread | Funding, review or credit? | Who decides | On what evidence | By when | What Tomás can ask, and whom |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |

Then draw the system as a map on one page. Put Tomás in the middle. Add every person or
body that decides something in the table, including the ones he has never met: the
funder, the institution, the editor. Draw arrows for money, decisions and credit, and
label each one.

Answer: which thread is not Tomás's to decide but is his to ask about now, before it is
too late to change?

## 2. The authorship memo (18 minutes, pairs)

1. **For thread 3,** write the half-page memo from [Career
   mechanics]({{ '/hidden-curriculum/career-mechanics/' | relative_url }}) section 5,
   seven lines: the question; what each side provides; data-use terms and what may be
   shown publicly; who does which task; the authorship expectation as currently
   understood and what would change it; what happens if the project stops; who may
   publish what in that case.
2. Write the two sentences Tomás says to Dr. Brennan to propose the memo. Frame it as
   scope, not trust.
3. **For thread 2,** list the [CRediT roles](https://credit.niso.org/) Tomás's work fits.
   Then write the short, low-temperature message he sends Dr. Idris. The draft already
   exists, so "before I start" no longer applies.

## 3. Your own map (12 minutes, private)

This section is yours. You do not have to share it.

1. What pays for your position, and until when? Write **known** or **guessed** next to
   each part.
2. Pick one project you contribute to. Is your authorship **agreed**, **assumed** or
   **unknown**?
3. Name one piece of work you have done that nobody would see on a CV: a review drafted,
   a script others run, data you cleaned.
4. Of everything above, write the one question you have been guessing the answer to, and
   whom you will ask. Draft it in one or two sentences.

## Peer check and exit ticket

Swap only your one question, not your map. Your partner answers one question: *could the
person answer it with a fact or a date, or does it only ask for reassurance?* Revise one
sentence.

Exit ticket: "The part of the system I understood least before today was ___. The question
I will ask is ___, to ___, by ___ (date)."

**Follow-through this week:** ask your question and write the answer down in a dated
note. [Professional Conduct in
STEM]({{ '/teaching/pathways/professional-conduct/' | relative_url }}) starts by asking what
you learned.

**Success criteria:** every thread has a named decider, and it is not always the PI; the
map shows at least one decider Tomás has never met; the memo states what Tomás delivers
first and says what happens if the work stops; your question can be answered with a fact
or a date.
