These pages map the site's existing teaching materials onto a course calendar. They
sequence sessions that are already packaged. They add no lecture content, and every
meeting links to a plan, worksheet, answer key, lab rubric or session kit that already
exists.

- [10-week course (quarter)]({{ '/teaching/syllabi/10-week/' | relative_url }}): 20
  meetings, three Professional Pathways workshops, about 30 contact hours and 30 outside hours.
- [16-week course (semester)]({{ '/teaching/syllabi/16-week/' | relative_url }}): 32
  meetings, eight Pathways workshops, about 48 contact hours and 44 outside hours.

Both are drafts built from the materials. Neither has been taught as a whole course.

## Meeting pattern

The default is **two 90-minute meetings a week**, called A and B on each map. Every
packaged plan on the site is timed for 90 minutes, so this pattern needs no re-timing.

For **one three-hour block**, run A and B back to back with a 15-minute break, as the
[four-session block]({{ '/teaching/sequence/' | relative_url }}) does for a half-day.
Move any reading listed for B so it is due before the block. For **50- or 60-minute
meetings**, split each plan at its activity boundary. The plans do not script that split.
Learners must bring their half-finished worksheet to the next meeting.

Outside hours on each map are estimates. Unit reading times come from each unit's
stated `time_estimate`. Module concept sets are estimated at about 30 minutes, and
finishing times are an allowance, not a measurement. Both maps come out at roughly one
outside hour per contact hour. That is lighter than the two-to-one ratio many US
institutions use for credit. Each map lists what to add if yours requires it.

## Audience and prerequisites

The maps assume upper-division undergraduates, post-baccalaureate researchers or early
graduate students. Introductory neuroscience helps. No programming is required: every
core session runs from printed rows, and Python is optional in Sessions 3 and 4. The
16-week map spends two weeks on null models and inference, so basic probability helps
there. No accounts or dataset downloads are required. One 16-week lab opens a public
volume in a browser viewer, with no account and an offline fallback.

Instructors should read the [Facilitator Guide]({{ '/teaching/facilitator-guide/' | relative_url }})
first. Its constraint applies to every meeting on both maps: at least half of contact
time goes to learner judgment compared against a reference or a peer. Each meeting on
the maps is an activity, a lab, a workshop or a talk with questions. None is a
lecture-only slot.

## How the pieces fit

- **The four-session block.** The [connectomics sessions]({{ '/teaching/sequence/' | relative_url }})
  are the spine. Learners write a study brief in Session 1, then audit it, write a methods
  record and write an analysis card. That brief is the thread both maps follow to the
  final project. The optional fifth session,
  [Ethics and Governance]({{ '/teaching/lectures/ethics-and-governance/' | relative_url }}),
  adds a licence, human-tissue and credit note to the same brief. Both maps include it.
- **Technical units.** The nine [Technical Course]({{ '/technical-training/' | relative_url }})
  units supply the pre-reading. Some also supply a lab, and each lab has its own rubric.
  Labs that need live data or a proofreading account are adapted or omitted, and each
  map says which.
- **Module session kits.** The [session kits]({{ '/teaching/sessions/' | relative_url }})
  list 3–6 hours per module. On these maps a kit gets one 90-minute meeting: learners read
  the module's concept set beforehand, and the meeting runs the kit's activity steps. A
  kit is used only when its scenario can run from the kit text. Some kits name patches or
  sample files that the site does not publish; the Module 03 and 05 worksheets are
  examples. The instructor has to supply those files.
- **Professional Pathways workshops.** The [ten workshops]({{ '/teaching/pathways/' | relative_url }})
  run alongside the technical work, one every two to four weeks, at their
  [MERIT]({{ '/models/' | relative_url }}) stages. They are not a block at the end. The
  10-week map uses the hub's three-slot short version. The 16-week map uses eight.

## The real-data lab

The planned MICrONS notebook does not exist yet. It will be a version-pinned, clean-rerun
query. Each map keeps a slot for it, labeled **planned; use offline fallback until the
MICrONS notebook exists**. Until then, the slot runs the capacity plan from Unit 04's lab,
which needs no data, plus a second pass through the Session 3 offline query. The
[Connectome Quality notebooks]({{ '/notebooks/connectome-quality/' | relative_url }})
page has reference code for learners who already have access. It is not a verified,
runnable notebook, so neither map grades it.

## Assessment

- **Artifacts carry forward.** Most weeks produce a written artifact that a later week
  revises or reuses. The final project assembles them with the
  [Module 25 kit]({{ '/teaching/sessions/module25/' | relative_url }}): a portfolio map,
  evidence captions and a revision plan, plus a short report and a talk with questions.
- **Keys are public and formative.** Every lecture and workshop answer key is published.
  Grade the learner's revision of their own study brief, not their first worksheet
  attempt. Keep any secure exam material separate from these pages.
- **Rubrics are local.** The lecture and workshop keys use 0–2 rubrics, the units use
  Not yet / Proficient / Strong tables, and the kits use minimum and strong criteria.
  None is a validated assessment instrument, and nothing here should be reported as one.
- **Pathways work is not graded on disclosure.** Collect only the shareable artifact each
  workshop plan names. The private parts, such as the STEM Identity and Purpose diagnosis,
  are never collected.

Each map ends with a suggested grading weight table. It is a suggestion; adjust it to
your institution.
